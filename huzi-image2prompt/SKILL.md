# Huzi Image2Prompt

## 核心原则

基于实际可见内容生成可复制的图片生成 Prompt。先忠实记录观察，再组织生成语言；推断必须可识别，未知参数不得编造。

## 工作流

1. **取得图片**
   - 优先读取用户附件；也可读取可访问的本地路径或图片 URL。
   - 使用宿主已有的图片读取或视觉分析工具。不要为单次任务临时实现视觉模型。
   - 图片不存在、损坏、无权限或无法解码时，明确阻塞原因，并要求用户上传图片或提供可访问路径。看不到图片时不得生成猜测性 Prompt。

2. **逐层观察**
   - 画布：横竖方向、宽高比、裁切和留白。
   - 主体：人物、物体、动作、表情、服饰、数量与相对位置。
   - 构图：前中后景、视线方向、对称、中心、对角线、俯拍或仰拍。
   - 环境：地点、天气、时间和背景元素。
   - 视觉语言：媒介、艺术风格、色板、光线、材质、纹理和细节密度。
   - 摄影语言：焦段观感、景别、机位、景深、运动感；只有画面支持时才写具体镜头词。
   - 文字与图形：逐字转录清晰可见的文字，记录字体类别、字号关系、颜色、位置和对齐；无法辨认时标为不可辨认，不得补字。

3. **区分证据层级**
   - **可见事实**：直接写入 Prompt。
   - **合理推断**：仅在有助于复现时使用保守措辞，如“约 35mm 视角”“类似丝网印刷”。
   - **不可恢复信息**：不得声称知道原始模型、LoRA、种子、采样器、步数、CFG、后期参数或创作者意图。

4. **组织 Prompt**
   - 默认顺序：媒介/风格 → 主体 → 动作与外观 → 环境 → 构图 → 光线与色彩 → 材质与细节 → 镜头/景深 → 宽高比。
   - 默认使用与用户相同的语言，写成模型无关的自然语言 Prompt。
   - 用户指定 Midjourney、Stable Diffusion、Flux 等目标模型时，再适配其语法；未指定时不要添加权重、采样参数或私有标签。
   - 保留画面中的原文，不翻译文字内容。文字生成不稳定时，提示用户后期排版更可靠。
   - 只有确有价值时才给 Negative Prompt；不要把未观察到的细节反向堆进负面词。

5. **校验后输出**
   - Prompt 中每个具体事实都必须能从图片观察得到，或明确属于保守推断。
   - 检查主体数量、左右位置、颜色、文字、宽高比和风格是否与图片一致。
   - 删除互相冲突、重复、空泛或只为“增强效果”而添加的词。

## 输出格式

默认使用以下结构，省略没有内容的可选段落：

````markdown
## Prompt
```text
[可直接复制的完整 Prompt]
```

## Negative Prompt（可选）
```text
[只保留与复现目标直接相关的排除项]
```

## 不确定项（可选）
- [对结果有实质影响的推断、不可辨认文字或不可恢复参数]
````

用户明确要求“只给 Prompt”时，仅输出 Prompt 代码块，不添加分析过程。

## 快速参考

| 场景 | 处理方式 |
|---|---|
| 写实照片 | 强调主体、环境、构图、光线、色彩、景深和焦段观感 |
| 插画或海报 | 强调媒介、轮廓、色板、图形关系、留白和排版 |
| 含清晰文字 | 原样引用文字，并注明位置、字体类别和层级 |
| 多张图片 | 分别编号分析；除非用户要求，不混合成一个 Prompt |
| 图片不可访问 | 说明具体原因，要求上传或提供可访问位置，不猜图 |
| 指定生成模型 | 保留同一视觉事实，只适配目标模型语法 |

## 示例

图片观察：横幅 16:9，米白背景上的透明玻璃香水瓶位于右侧三分之一处，左侧留白，柔和侧逆光形成浅金色高光和淡灰阴影，极简产品摄影。

输出：

````markdown
## Prompt
```text
极简产品摄影，横幅 16:9，米白色无缝背景，一个透明玻璃香水瓶位于画面右侧三分之一处，左侧保留大面积负空间，柔和侧逆光穿过玻璃形成浅金色高光，瓶体下方落有淡灰色柔和阴影，干净克制的构图，细腻玻璃材质
```

## 不确定项
- 无法仅凭图片可靠确定具体灯具、焦段或香水品牌。
````

## 常见错误

| 错误 | 修正 |
|---|---|
| 为画面添加“电影感”“杰作”“8K”等万能增强词 | 只保留图片实际呈现的风格和质量特征 |
| 把推测写成精确事实 | 使用“约”“类似”，或移入“不确定项” |
| 忽略左右、层级、留白和宽高比 | 在 Prompt 中明确空间关系与画布比例 |
| 自动翻译或补全图片文字 | 原样转录；不可辨认部分明确标注 |
| 声称恢复了原始生成参数 | 说明这些参数无法仅凭成图可靠恢复 |
| 图片不可访问仍给出通用 Prompt | 停止推断，要求可读取的图片输入 |
