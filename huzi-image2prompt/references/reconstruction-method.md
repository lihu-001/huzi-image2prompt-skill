# 结构优先的参考图重建

在完成初步观察后、选择平台 adapter 前使用本规范。目标不是列出原图包含哪些物体，而是重建让这些物体以当前比例、位置、遮挡、明暗和空间关系出现的画面秩序。简单平面图可以省略不适用字段，但不得颠倒“结构先于装饰”的优先级。

## 1. 测量约定

- 严格复现确有需要时，将画布左上角记为 `(0, 0)`、右下角记为 `(1, 1)`，记录近似中心点、边界、直径或间距。
- 数值只表达可见比例，不冒充像素级测量；证据不足时改用“上方约三分之一”“宽度接近主体一半”等关系描述。
- 同时记录画布比例、主体包围区域和关键锚点。优先使用相对比例，使规则不依赖原始分辨率。

## 2. 六层重建顺序

### 骨架与轴线

- 将画面压缩成外轮廓、主要几何体、中心轴、对角线、圆轴和透视汇聚线。
- 记录主体完整还是被裁切、视觉重心、主方向，以及轮廓在哪些位置发生转折。
- 先确认主体属于什么形制；不能用“同类物体”替代原图中特有的分体、开口或不对称结构。

### 比例与关键锚点

- 记录主体宽高关系、主体占画面的比例、顶点和底边位置。
- 为身份关键部件记录中心、大小、朝向，以及它们相对主体和彼此之间的距离或比例。
- 关键比例存在冲突时以可见轮廓为准，不用更多局部细节掩盖错误。

### 负形与遮挡

- 观察主体外侧的背景形状，以及主体内部的缝隙、开口、楔形、孔洞和间隔。
- 记录负形的方向、宽窄变化、是否贯通、两端落点及其与轴线的关系。
- 明确“谁遮挡谁”、遮挡发生在哪里和约略可见比例。物体名称都正确但遮挡方向错误，仍属于结构失败。

### 三值明暗体积

- 先把画面概括为亮面、中间调和暗面三大区域，再记录必要的细微过渡。
- 明暗必须解释几何朝向：写明光从哪里来、哪一结构面受光、哪一结构面转入阴影。
- 标记最亮和最暗锚点，防止模型把局部发光、夕阳或高光扩张成整幅统一滤镜。

### 空间与尺度层级

- 建立从背景到前景的有序深度图，而非只列“天空、建筑、河流、人物”。
- 记录层之间的遮挡、尺度递减、对比度下降、空气透视、雾尘、倒影和长焦压缩等可见关系。
- 远景不应获得超过主体的对比度和纹理；微小人物等尺度参照必须保持其相对大小。

### 色彩、材质与纹理

- 骨架、比例、负形、主要遮挡和明暗体积完整后，才编译色彩、材质、铭文、裂纹、颗粒和装饰图案。
- 纹理只描述表面，不能改变承载它的形体，也不能把次级装饰升级为画面主体。
- 无法辨认的纹样属于 P2；不得为了细节丰富而虚构可读文字或精确符号。

## 3. 纹理门禁

编译 Prompt 前检查：

- P0 外轮廓、完整取景、关键比例、负形和主要遮挡必须已经明确。
- 任何高显著装饰词前必须先说明它依附于哪个结构、处于什么位置、是否被遮挡。
- 若 P0 缺失或相互矛盾，先修正 Canonical Visual Spec；不得通过添加“精细、复杂、高细节、真实材质”等词继续推进。

该门禁控制信息优先级，不要求最终 Prompt 分成六个显式阶段。平台 adapter 应把它编译成各自最有效的表达。

## 4. 结构优先评分

当用户提供生成结果用于比较时，按以下权重诊断；评分用于定位误差，不声称是精密视觉测量：

| 维度 | 权重 |
|---|---:|
| 外轮廓与骨架 | 30 |
| 比例与关键锚点 | 25 |
| 负形与遮挡 | 15 |
| 明暗体积 | 10 |
| 空间与尺度 | 10 |
| 色彩关系 | 5 |
| 材质与纹理 | 5 |

P0 采用硬门禁：任何身份关键关系缺失或与原图冲突，都判定本轮结构未通过，不得由纹理分数抵消。尤其是错误裁切、错误宽高、错误负形和主要遮挡反转。

## 5. 对比与纠偏

用户提供生成结果时：

1. 对照 Reconstruction Spec 判断关系是否存在，而不是只检查物体名称是否出现。
2. 每轮只选择影响最大的一个或两个误差类别，锁定已经正确的 P0 字段。
3. 结构事实识别错误时修正 Canonical Visual Spec；事实正确但平台仍漂移时只调整相应 adapter。
4. 先修骨架、比例和负形，再修明暗与空间，最后修材质纹理。
5. 不因单次结果失败就增加跨场景永久规则。

只在用户明确要求生成或连续迭代时调用生成能力。自动纠偏最多进行三轮；仍未通过时报告剩余的最高权重误差和建议，不无界重试。用户明确要求继续时可以开始下一组迭代。
