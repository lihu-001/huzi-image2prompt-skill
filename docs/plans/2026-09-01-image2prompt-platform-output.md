# 图片反推多平台输出实施计划

> **执行要求：** 按测试驱动方式先运行当前技能基线，再修改、复测、打包和提交。

**目标：** 让 `huzi-image2prompt` 默认生成自然语言、GPT、Grok、Midjourney 的中英文可直接粘贴 Prompt。

**架构：** 保留单一视觉事实源，按四种平台规则派生八个独立代码块。关键歧义在生成前询问；不可恢复参数不询问、不编造。

**技术栈：** Agent Skills Markdown、YAML、JSON 评估、Python 打包校验。
