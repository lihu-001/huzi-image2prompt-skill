# Huzi Image2Prompt 实施计划

> **执行要求：** 按测试驱动方式完成技能，先记录无技能基线，再实现并复测。

**目标：** 创建可开源发布的 `huzi-image2prompt` Agent Skill，把用户提供的图片解析为忠实、可复制的图像生成 Prompt。

**架构：** 仓库根目录保存开源说明、许可证与评估材料；`huzi-image2prompt/` 仅保存可打包的技能文件。技能不绑定某个视觉模型或私有 API，而是要求代理使用宿主已有的图片读取或视觉分析能力，并采用固定的“观察—组织—校验—输出”流程。

**技术栈：** Agent Skills `SKILL.md`、YAML Frontmatter、Markdown、Python 技能校验与打包脚本。

---

### 任务 1：建立评估基线

**文件：**
- 创建：`evals/evals.json`

**步骤：**
1. 定义写实照片、含文字海报、图片不可访问三个场景。
2. 在不加载目标技能时运行场景。
3. 记录自然输出中的不稳定结构、未经观察的细节和错误处理表现。

### 任务 2：实现技能

**文件：**
- 创建：`huzi-image2prompt/SKILL.md`

**步骤：**
1. 使用官方初始化脚本创建技能目录。
2. 删除无用的示例脚本、引用和资产。
3. 写入名称、触发描述、核心原则、工作流、输出契约、快速参考、示例和常见错误。
4. 明确区分可见事实、合理推断与不可恢复参数，禁止虚构图片内容。

### 任务 3：补齐开源项目材料

**文件：**
- 创建：`README.md`
- 创建：`LICENSE`
- 创建：`.gitignore`

**步骤：**
1. 说明用途、安装方式、触发示例、输出结构和兼容性。
2. 使用 MIT 许可证。
3. 忽略本地缓存和临时构建产物。

### 任务 4：验证与打包

**文件：**
- 生成：`dist/huzi-image2prompt.skill`

**步骤：**
1. 运行技能快速校验。
2. 使用同一批评估场景加载技能复测。
3. 对实际图片执行一次读取与 Prompt 生成冒烟验证。
4. 运行打包脚本并检查压缩包内容。
5. 检查版本库状态；无远程仓库时仅保留本地可提交成果。
